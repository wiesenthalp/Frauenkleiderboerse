# Kassensystem

Dies ist ein einfaches Kassensystem, das mit Streamlit und Pandas entwickelt wurde. Es ermöglicht die Erfassung von Verkäufen, die Erstellung von Rechnungen und die Anzeige von Statistiken.

## Installation

1. **Python installieren:**
   Stelle sicher, dass Python 3.7 oder höher auf deinem Computer installiert ist. Du kannst Python von [python.org](https://www.python.org/) herunterladen.

2. **Abhängigkeiten installieren:**
   Öffne das Terminal (oder die Eingabeaufforderung) (zum Beispiel über WINDOWS, "cmd") und navigiere zum Ordner, in dem das Projekt gespeichert wurde (Adresse im Ordner kopieren, in Eingabeaufforderung "cd " schreiben und Adresse einfügen + ENTER). Installiere dann die Abhängigkeiten mit folgendem Befehl (folgenden Text kopieren und in Eingabeaufforderung einfügen + ENTER):
   
   pip install -r requirements.txt

3. **Programm starten:** 
    Im selben Ordner, in dem sich die app.py befindet, führe den folgenden Befehl aus, um das Programm zu starten (folgenden Text kopieren und in Eingabeaufforderung einfügen + ENTER):

    streamlit run app.py

    Streamlit öffnet das Kassensystem in deinem Webbrowser.
